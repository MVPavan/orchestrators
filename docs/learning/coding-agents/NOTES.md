# Teaching notes

- Teach at the systems-engineering level; avoid syntax and implementation-style
  detours.
- Pi comes before Codex. Do not create Codex learning artifacts until the Pi
  mastery gate allows it.
- Use one small lesson at a time and ask only one Socratic question before
  moving to transfer.
- Do not record exposure as learning. Create a learning record only after the
  learner demonstrates an accurate teach-back or transfer prediction.
- Token use matters. Offline source and graph work is preferred; pause before
  any additional paid or delegated model session.
- Tool answers are retrieval evidence, not teaching authority. Reconcile them
  against source before using them in a lesson.
